# HR Interview CRM - Full Stack

## Modules
- CRM dashboard: total interviews, today, pending, selected, rejected, pending joining, joined, college proposals
- Candidate interview pipeline for BDA, Software, Java, Python, React, Node, HR and custom roles
- Google Meet link on every interview
- Interview date/time, round, interviewer, notes and follow-up date
- Joining date + Pending Joining / Joined / Declined tracking
- College placement / internship / BDA / software hiring proposal CRM
- Daily interview report
- Search and live status updates
- MongoDB persistence

## Backend
```bash
cd backend
cp .env.example .env
npm install
npm run dev
```
Configure MongoDB Atlas in `.env` if required:
`MONGO_URI=mongodb+srv://USERNAME:PASSWORD@cluster.../hr_interview_crm`

Backend: http://localhost:5000

## Frontend
Open another terminal:
```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```
Frontend: Vite will show local URL, typically http://localhost:5173

## Important API routes
- GET /api/dashboard
- GET/POST /api/interviews
- PUT/DELETE /api/interviews/:id
- GET/POST /api/proposals
- PUT/DELETE /api/proposals/:id
- GET /api/reports/daily?date=2026-08-25

## Google Meet
Paste the Meet URL received/generated by HR into the Google Meet Link field. Clicking `Open Meet` launches it.

## Interview meeting proof photos
Each interview row now has an **Add Proof** action. HR can upload up to 5 interview/Google Meet proof images per upload (8 MB each), save an optional proof note, preview thumbnails, and open the original image. Proof metadata is stored in MongoDB while image files are stored under `backend/uploads/meeting-proofs` and served from `/uploads`.
